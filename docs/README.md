# 文档与验证记录

[English](README.en.md)

从[架构说明](architecture.md)、[命令参考](commands.md)和[元件入库](component-intake.md)开始。版本管理见[保留策略](retention-policy.md)，初始筛选的验收事实见[初始验收](verification.md)。这些说明均有英文版。

`selection.json` 和 `asset-manifest.json` 描述当前范围和实际资源。`cad-restoration.json` 记录现用图纸恢复及哈希校验；`example-verification.json` 与 `runtime-verification.json` 保留对应时点的检查结果。较早验证记录不会因为发布或补资料而自动代表一次新的实物验收。
