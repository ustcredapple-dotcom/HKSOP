# Homepage assets

[中文](README.md)

`hksop-cover.svg` is an English cover in a dark technical-drawing style. It retains the approved HKSOP r9 logo outlines, lettering and proportions, changing only color and page placement. The cover stack, `post-adapter-system.svg` and `sketch-to-system.svg` are explanatory vector diagrams, not manufacturing drawings.

The imaging sketch, R10 optical layout, R11 assembly and DoublePass R8 layout/assembly are real project artifacts copied byte-for-byte. Existing Chinese annotations remain in the source images. See [sources.json](sources.json) for their stages, original filenames and hashes, and the [case study](../workflow-case-study.en.md) for context. These documentation images do not expand the distributed component or importable-project scope.
