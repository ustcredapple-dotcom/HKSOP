# 首页展示资源

[English](README.en.md)

`hksop-cover.svg` 是深色工程图风格的英文封面，沿用已定稿 HKSOP r9 标识的轮廓、字形和比例，仅改变颜色与页面内位置。封面堆叠、`post-adapter-system.svg` 和 `sketch-to-system.svg` 是解释性矢量图，不能用作制造图。

成像手稿、R10 二维光路、R11 三维总装和 DoublePass R8 布局/总装均来自实际项目，按原字节复制。原图中的中文标注保留。各自阶段、原文件名及校验值见 [sources.json](sources.json)，案例说明见[手稿到三维](../workflow-case-study.md)。这些展示图片没有扩大元件包或可导入示例的收录范围。
