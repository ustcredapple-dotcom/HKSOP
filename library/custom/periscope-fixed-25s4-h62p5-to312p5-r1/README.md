# 25-S4 R3 双固定镜光爬架

[English](README.en.md)

上下镜组各用一套 12.5 mm 底座、ZZ-13-M1 转接板和 MT-FLF1S 固定式镜架。直板上的两组名义光高为 62.5 mm 和 312.5 mm。底座宽 45 mm，与直板齐平，四孔中心距 50 × 25 mm。25 mm 孔网的横向光轴相位为 12.5 mm。
