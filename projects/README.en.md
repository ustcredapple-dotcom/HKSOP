# Example projects

[中文](README.md)

This directory contains three current project JSON examples: [Basic Reflection](基础反射示例/README.en.md), [1-to-3](一分三示例/README.en.md), and [DoublePass](DoublePass示例/README.en.md). Import the selected folder's `project.zzoptics.json` in the editor.

`project.json` identifies the engineering file, `library-lock.json` records the current library version, `example.json` preserves provenance and compatibility edits, and `results/index.json` lists actual project deliverables. Examples reference the shared library rather than duplicating geometry or drawings. No project history is included.
