# 示例项目

[English](README.en.md)

本目录只收录三个当前工程 JSON 示例：[基础反射](基础反射示例/README.md)、[一分三](一分三示例/README.md)和 [DoublePass](DoublePass示例/README.md)。在编辑器里导入对应目录的 `project.zzoptics.json`。

`project.json` 描述工程入口，`library-lock.json` 记录当前元件库版本，`example.json` 保存来源与适配说明，`results/index.json` 列出实际项目成果。示例引用公共元件库，不重复打包模型或图纸，也不附带历史工程。
