# 1-to-3 layout

[中文](README.md)

Import [project.zzoptics.json](project.zzoptics.json) in the editor. This project contains 18 kit instance(s). Demonstrates a branching layout assembled from several standard kits.

STEP models, top views, and component drawings are shared from the library rather than repackaged here. See [example.json](example.json) for provenance and compatibility edits. The original optical settings and physical/manufacturing acceptance limits are retained.
