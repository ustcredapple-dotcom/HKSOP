## 版本保留规则（用户约定，2026-11-08）

本规则优先于本 skill 及其旧参考文件中要求永久保留全量版本、旧快照、旧 CAD 或整批历史交付的条款，适用于 HKSOP 和标准光学协议工作。

- 引擎只保留当前有效实现；元件库只保留当前有效定义及其正在使用的 CAD、图纸、渲染与必要说明。不同现用型号/安装变体可以共存，不能仅凭文件名含 R1/R2 就认定为历史。
- 具体项目保留当前最终工程 JSON、当前最终 3D/CAD、图纸、加工包、客户包及采购清单。只在当前项目确实需要时保留这些成果。
- 历史版本只保留具体项目人工确认或正式交付的工程 JSON 里程碑，并按内容去重。不要保留自动保存、临时调试或元件入库演示的全量历史。
- 不保留旧引擎、旧元件库快照、旧项目 3D 模型、旧 CAD/图纸、旧加工/客户包或整套旧复建资料。不能为打开历史 JSON 而暗中保留这些历史依赖。
- 历史 JSON 仅用于布局追溯；重开时对照当前元件库检查兼容性，不能宣称可精确复现已删除的旧几何。当前实际项目专用元件应作为现用定制元件正式登记，而不是用整库历史快照承载。
- 入库事务允许短期回滚暂存；成功完成并验收后立即清理。生成目录、缓存和过期暂存不作为永久版本。
- 完整备份也只包含上述保留集合，不能再次把全部历史版本收进备份。更新前核对当前依赖，更新后核对文件和链接、重新生成目录大小报表。
- PROJECT_LOG、版本号、来源哈希及验收结论可保留为精简文字记录，不等于保留旧版实体文件。整理限定在本次获授权的工作区，不自动扩大删除其他原项目、服务或数据库。

先读 [工作区适配](../HKSOP_CONTEXT.md)，读取项目当前版本信息与实际验收记录，遵循 ../zzlab-modular-optics/SKILL.md 的制造要求。

冻结输入工程、元件修订、每个加工文件和 BOM 的 SHA256。按加工零件列数量、材料、表面处理、螺纹与装配要求；外购件另列采购清单。每个可加工件提供对应 STEP 和可读工程图；DXF 只作为补充，不替代三视图。激光刻字包含字体/位置、实际刻字文本、DXF 和定位图及对应哈希。

使用引擎 exports 的原验收约束；专业预览警告不能被删除后作为放行依据。缺图、缺尺寸、未核查的孔或未确认版本写入 blocking-items.json。未解除制造阻塞时交付 review 状态，不冠以 ready。

输出放 projects/<project>/results/manufacturing，附 manifest.json、验收记录和 README.md。验证压缩包可解压、清单内所有文件哈希一致、数量与已冻结工程一致，再追加日志。
