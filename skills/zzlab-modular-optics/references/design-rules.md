# 设计规则与器件例外

## 基准和公制高度

默认世界坐标以主面包板上表面 Z=0、万能柱中心轴为竖向基准；X/Y 光路方向按实际装配声明。绘图零件局部坐标可取功能底面 Z=0，但必须保存局部到装配的刚体变换。

- 当前标准光高62.5 mm，柱高12.5、25、37.5、50…mm。特殊激光器/爬架光高按实际需要取12.5 mm倍数。转接厚度一般**不必**是12.5的倍数。
- 改版不要把每件简单下降1 mm或把所有数字乘25/25.4。例如柱25.4→25少0.4，器件自身不变，光高63.5→62.5的余下0.6由有效转接高度吸收。
- 商用1 inch口径仍为25.4 mm，0.5 inch为12.7 mm；CS接口、SM螺纹等不公制缩放。厂家柱底座是否已计入标称柱高，必须看实际模型。
- 镜面/透镜基准与柱中心的关系同时在纵向和横向核对，不能只核对Z。波片可放松沿光轴偏置；不意味着可以错开通光孔中心。

## 真实光学面

反射镜：在厂家几何中找到挡住镜片的真实后座/肩面，排除前缘、弹性夹舌和镜架外壳。给出座面点 `p_seat`、从座面指向镀膜面的单位法向 `n`、镜片厚度 `t`；镀膜面点为 `p_seat + t*n`。把座面和法向一起变换到总装坐标，测光束交点与柱中心的差。

用户本批镜片厚度：0.5 inch=3 mm，1 inch=6 mm，2 inch=12 mm。更换镜片型号后重新取其真实厚度与镀膜方向。此次基准纠正允许测得偏差≤0.5 mm保留；不得把这个宽限写成孔位或平面加工公差。不要用挪动显示用镜片的办法掩盖后座不接触。

透镜：声明所采用的安装光学基准面与光轴，依据产品/原设计确认；包围盒中面、透镜主平面和机械安装面不是可以随意互换的概念。

相机：感光面而非壳体前脸、CS法兰或保护窗放在柱中心。既有FLIR试制件的感光面为估算，用户已允许可修正试制；待确认标签必须继续带入图纸和总装。不能因为STEP导入成功就取消该标签。

## 销、螺钉和定位

- 新孔位置从正式万能柱源和配套面提取，保留孔轴、入口面、螺纹和销孔的对应关系。不凭图片把“光学中心”“中心螺孔”“备用M4孔”混为一谈。
- 当前正式柱的对销孔间距10 mm、半径5 mm，偏置M4半径8.5 mm；销孔有效圆柱深4.2 mm、偏置M4名义深8 mm。短柱中心M6与较高柱顶部中心M4不可混用。以上是当前接口记录，改柱版本后重新核对。
- 90°调整指镜架相对柱孔阵列重新定向，不是把整套一起转而保持原遮挡。当前一种已核验映射为转接M4=(-8.5,0)、销=(0,±5)，0°状态柱clock=90°、-45°状态柱clock=270°；这是特定前侧锁紧布置，不能直接复制给所有器件。
- 柱有不同钟向以及额外M4孔。一个位置合适的紧固螺丝可以满足本项目既有结构；不用为了凑双螺丝加长臂。无需坚持“只有中心被占才准用备用孔”，应以光学基准、接触支撑与工具可达为准。
- 两侧连接应是一侧螺纹、另一侧间隙/沉孔，不把同一紧固件穿过的两件都攻牙来定位。确认夹紧堆叠、螺纹啮合和盲孔底余量；需要相对转动的界面不能锁死。
- Ø2销与Ø2.01孔确定方向。孔深、孔距和盲/通状态依接口确定；Ø2.01只是标称尺寸，不能凭此宣称某一配合公差。盲孔标明有效圆柱深、钻尖余量，防止穿入沉孔/工作面。
- 螺钉孔使用Onshape所选标准/紧固件/配合的默认系列。此项目已用的M4间隙沉孔例为Ø4.3通、Ø8.25深4；M3例为Ø3.2通、Ø6.5深3。它们是既有配置记录，不代表所有标准的通用值；新规格先确认实际选项。不要把圆柱沉孔改成锥形沉头孔。
- 用户不要求实体螺丝/销钉。核验时可用临时头部、杆部、扳手包络，交付模型不必增加这些零件；安装说明仍须能解释锁紧方向和顺序。

既有Onshape界面实测配置为 `Metric / Counterbore / Clearance / Close`，记录见 `work/assembly_audit_20261004/onshape_defaults/defaults.json`（项目根路径见project-map）。通孔径/沉孔径/沉孔深：

| 规格 | 通孔径 | 沉孔径 | 深度（mm） |
|---|---:|---:|---:|
| M2 | 2.2 | 4.4 | 2 |
| M2.5 | 2.7 | 5.5 | 2.5 |
| M3 | 3.2 | 6.5 | 3 |
| M4 | 4.3 | 8.25 | 4 |
| M5 | 5.3 | 9.75 | 5 |
| M6 | 6.4 | 11.25 | 6 |

不为挤空间自行缩小该默认沉孔，不把本来不需沉孔的孔强加沉孔，厂商原孔保持。

## 阻块和紧凑结构

先检查板状器件是否已有销定位。没有时，平行于镜面/器件基准面的短后挡可抵住有效平面以定向；先核验真实接触面，再建挡块。当前项目里没有提供该定位作用的侧长臂、侧凸块应删除。不是“所有阻块都删掉”，也不是“任何侧面接触永远无效”。

不得用没有夹紧机制的滑槽、悬空挡块或不接触零件的凸块假装定位。转90°能露出螺丝时，优先比较该布置，保持实际镜面位置与销孔钟向一致。

沉孔被镜架遮一小部分可考虑预放螺丝。验证顺序：螺丝能先放入→器件能装上→扳手能进入并转动/换位→螺丝可锁紧且不顶底→可按说明拆卸。不能只看螺钉轴线无遮挡。

局部孔相通也不自动等于螺钉碰撞或定位失效。现有16号件的沉孔与销孔局部相通，保留约307°销孔圆周，是已记录的局部方案；核对剩余支承、去毛刺和配合，不能因此机械加上“T槽/侧窗/两层/所有净壁至少1 mm”的通用规则。也不能把这个例外推广为所有破孔都可接受。

转接件尽量方形、单件，去掉无功能的大底座。增加拆分的依据应是装配路径、加工可达或调节机制，不是解决不了布局时的默认选择。短内圆角、退刀槽按加工需要设置，不把“少圆弧”理解为要求不可铣的尖内角。

## 器件特定要求

| 器件 | 设计要求/例外 |
|---|---|
| 0.5 inch PBS | 有固定和可调需求。上下两件并非先验必要；根据预装螺丝和真实紧固路径判断能否合并。可调界面的独立运动不能布尔合并掉。 |
| AOM | 麓邦自由空间型号；复用现有可调PBS的AMP-1R调节结构，另设计到AOM的转接。固定侧与运动侧不能合并锁死，也不能另造微调机构替代。AMP不绕柱共心转动，不能保证整个调角范围恒高。核对具体型号孔位、光口、散热面和接头空间；不同型号不能假定壳体一致。 |
| 隔离器 | 使用麓邦带官方安装罩的版本，保留罩的安装接口。较大/偏重器件用中心支撑或两个万能柱分担，避免单侧偏心支撑。 |
| 2 inch反射镜 | 固定、可调镜架均保持单万能柱方案，不照搬大隔离器的双柱规则；0°/45°按该器件任务要求提供。 |
| 波片 | 单/双版本；半英寸当前不做45°版。波片平面允许沿光轴偏置，以减少无谓分体；仍核对通光和转动空间。 |
| PD | 优先按用户指定的麓邦实际型号与官方机械接口配套，不造出无依据的通用壳。 |
| FLIR相机 | 既有型号BFS-U3-16S2-CS；真实感光面待确认的试制状态见上文。 |
| 滨松SLM | X15213-03B无水冷光学头为既有源；保留光学工作面、外壳接口及线缆空间，以对应源图核实。 |
| 标靶/标尺 | 小巧，可接主板或万能柱；刻度值必须与真实几何和板面基准一致，不能只改文字。 |
| 阶梯定位销 | 上Ø6.38、下Ø4.98，底端及肩处倒角，上端横向拔出孔；用户明确不要刻字。长度/倒角以最新R3源为准，不按光高比例缩放。不能把插入螺纹孔的定位效果宣称为已保证的精密公差。 |
| 一体爬架 | 当前R2为整块316L的45 mm宽L形结构，输出50/62.5，输入100–200每12.5一档；复用12.5柱和1 inch可调镜架。不得恢复R1的75 mm宽拼装结构。现有堆叠37.5输出碰撞，50为已检验的最低网格档，不是所有未来结构的物理极限。 |

当前PD感光面、CSD20光阑叶片面和隔离器内部Faraday作用面也存在原厂基准未确认项。按相应装配说明保留限制，不能把“外壳/安装基准已对齐”写成“内部光学面已确认”。

爬架需把真正反射面和水平柱的钟向一起变换，计算折线路径。以主面包板孔网定位整个爬架，使横向和纵向自动对齐；安装孔坐标可以是为补偿实际光学基准而计算出的非整12.5数值。所有标注高度仍按真实光轴位置核对。


## 相邻小面包板净缝（2026-11-06 用户约定）

标准要求 `board-clearance-1mm-v1`：同一安装层相邻独立小面包板的真实板边最小净缝为 **1 mm**，不允许贴边或实体重叠；已有更大间隙保持。主承载板与其上小板的正常上下叠放不属于此间隙检查。

- 优先收缩有余量的板边，可单边退让1 mm或两侧合计退让1 mm。保持光学器件的世界坐标、角度、光高及全部现有安装孔的世界坐标和孔型；用户明确要求的整板移动单独实施、单独记录。不得通过缩放板和孔阵列制造缝隙。
- 以真实外轮廓、内凹缺口和板层高度逐对检查；不得只比较矩形包围盒，也不能用画布线宽或碰撞豁免代替物理净缝。
- 修边前后检查底座承托、通孔/沉孔的完整边壁、固定与工具可达。没有足够材料余量的边保留并列出例外，另行调整板形/布局；1 mm板间缝不等同于通用孔壁厚或加工公差。
- 参数板修边时保留原孔网基准；异形板或单边退让若当前JSON参数不能准确表达，登记独立的板型修订并保留原版本，不把旧STEP/PDF标为修边后的制造文件。
- JSON检查回执列出全部板对、最小净缝、修边量、原孔/光学基准保持情况与未完成项。仅完成本地轮廓/JSON验收时，明确CAD、加工图和Onshape同步状态；用户另有明确缝宽要求时以当次要求优先。


## 小板固定孔与万能柱两螺钉（2026-11-06 用户补充）

紧凑小面包板允许把固定沉孔安排在万能柱底座下方，采用“先把小板锁到主板，再安装万能柱”的顺序。常规万能柱保留两个有效、分开的固定螺孔即可，优先选对角孔；不要为保留四颗柱脚螺钉而否决可装配的柱下沉孔。此条不自动把位移台、专用接口或双柱总成的总固定要求降为两个孔。

- 沉孔螺钉头须完全不高于板面；核对头部尺寸、板底余厚、主板实际螺纹重合、螺纹啮合与底部余量。标明先装/先拆器件以及装配、锁紧、拆卸顺序。
- 沉孔占用的孔不能再计作柱脚可用螺纹孔；每根柱逐一列出保留的至少两个孔。需要省去邻近备用孔来留壁厚时，登记新板型，区分新制板与已加工板；不可把已存在的破孔假定为实心材料。
- 小板固定到主板的螺钉数量独立判断，不把“每柱两个螺钉”混同为“每块板必定两孔”。本轮P12仅两个有效主板重合位的双孔方案是具体规划例外，应保留其孔距、外伸及未实测状态。
- 俯视遮挡只提示复装顺序，不单凭覆盖判不合格；也不能用装配顺序豁免真实实体冲突、孔位错配或材料不足。
