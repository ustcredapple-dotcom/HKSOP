# 给师傅的加工包

2026-11-06 用户认可 Cooling re-pump 合束模块 R7，并要求以后加工包沿用此做法。默认适用于交给加工师傅的零件/模块加工包；用户当次明确的范围和格式优先。内部设计归档、元件库安装包、总图册另按各自协议维护，不混入本包。

## 文件结构与命名

- 按独立加工件分类，一种零件一个子文件夹；同款多个实例共用图模，在加工清单写件数。不同几何、规格或修订分别列项。底面包板属于本次加工范围时也独立列项。
- 文件夹和文件采用简洁、人能读懂的名称，必要时带尺寸、型号以区分；零件短编号贯穿图纸和清单，但不以内部 ID 或哈希代替名称。用户命名的模块用于包名、清单和相关图纸标题；产品铭牌/镭雕内容按已确认范围更新。
- 每个零件文件夹仅放：三视图加工 PDF、当前单件 STEP、镭雕定位 PDF、实际镭雕用 1:1 mm DXF。加工 PDF 保留必要的孔表、剖视、底视和局部详图。多打标面可用同一定位 PDF 分页、每面独立 DXF；明确免打标的零件不制造空镭雕文件，在清单注明即可。
- 压缩包根目录直接放一份简洁的 `加工清单.pdf` 和各零件文件夹。不要额外嵌套一层同名包目录。
- 不放总装 STEP、装配图、完整总册、光路 JSON、源码、原厂参考、示范附件、审核记录、哈希清单、日志、README、重复预览图或系统隐藏文件。上述必要内部资料留在包外的工作/归档目录。不要为简化目录删除必要加工尺寸或隐去关键未定参数。

```text
模块名_加工包_修订.zip
├── 加工清单.pdf
├── 01_底面包板_尺寸/
│   ├── 底面包板_三视图加工图.pdf
│   ├── 底面包板_三维模型.step
│   ├── 底面包板_镭雕定位图.pdf
│   └── 底面包板_顶面镭雕_1比1.dxf
└── 02_零件名称/
    └── 同类必需文件
```

加工清单至少列：器件/零件名称、材质、表面处理、件数、文件位置（相对文件夹路径）。可加简短编号和总件数；一页能放下就用一页。同款数量不得因多个视图、打标面、套件或实例重复累计。采购标准件和用户自备件不计入加工件数，确有必要时用一句说明。

本次示范的 6061、黑色阳极氧化、白色镭雕、75 mm 光高及底板尺寸是该模块参数，不据此覆盖未来任务已确认的材料、工艺或尺寸。

## 光路模块底板的辅助镭雕（2026-11-06 补充，2026-11-07 增补框内文字）

光路模块的底面包板（含小面包板）默认包含装配辅助镭雕，不能只刻板号或模块名称就视为完成；用户明确要求空白底板或免打标时除外。按当前已确认布局生成，保留光路和器件位置标记，并在每个器件定位方框内补齐文字标识：

- **器件定位框与编号**：逐一对应实际底座/安装占地、安装锚点和器件 ID。标准35×35 mm底座可采用中心线37×37 mm框、每边1 mm余量；不同底座按真实几何确定，标清框线宽及余量，不把商用件外廓当底座。相邻框不得混淆，合并套件按实际安装单元标记。
- **每框中文名与对应英文刻字**：每一个器件定位框内部必须同时刻上该位置所放器件的中文名，以及对应转接件上已确认要镭雕的英文字样；英文从当前修订的转接件打标源逐字复用，保留大小写、型号/编号和符号，不另译、不用通用简称或器件 ID 代替。两项均为实际板面镭雕内容，不能只放在框外图例、清单或定位 PDF 中。合并套件按实际安装单元对应名称与英文；多个框对应同款器件时每框都刻，不能仅标一次。英文尚未确认时列为待补，不凭猜测生成，也不宣称该框已完成。
- **安装朝向和点位**：标出可辨识的器件方向基准（例如本地+Y的T形刻线，不能冒充出光箭头）、底座中心和需要使用的固定孔点位。标明点位究竟是柱轴/安装锚点还是实际光学中心；有偏置时分别处理，不把辅助标记变成新增钻孔。
- **光路引导**：从本版JSON/核验光追或已确认真实光学基准投影到板面，包含名义光路、传播方向、输入/输出与必要的波长/板面光高标识。说明板面线是装调引导，不代表光在板面传播；不要凭截图手绘替代坐标。
- **功能预留区**：当前布局确有激光器或其他需预留的装置时标范围与用途；没有该器件不照搬示范区域。材料、板厚、光高和孔阵列沿用本任务，不随示范改变。
- **HKSOP 黑白 logo**：每块面包板（含小面包板）默认实际镭雕一处完整标识，按[固定矢量与排版规则](breadboard-logo.md)使用图形＋`HKSOP`＋`Hong Kong Standard Optical Protocol`。保持全部比例和字形内孔，放在无孔口/器件/其他标记冲突的可见区域；纳入本板机器 DXF 与定位 PDF，不只放在图框或封面。

按当前孔口/沉孔真实外缘、板边、螺钉和邻近标记设置并记录避让余量；允许线框/光路线在孔口处有明确断口，文字须整体移位避免被裁残。框内中英文可分行，在框内调整排版和实际字高，保持完整可读并避开孔口、光路线及其他标记；空间不足时列出待解决的排版问题，不能省略文字、移到框外或缩成不可读小字。保持器件编号可读，核对框、中文名、英文刻字、点位、方向与实际布局一一对应，线条交叉处避免重复打标。

这些框、框内中文名和英文刻字、点位、T形朝向和光路是**需要实际镭雕的文字与功能图形**，须进入底板1:1 mm闭合轮廓DXF；中英文字形均转为完整矢量轮廓，核对中文缺字、内环与阅读方向，不依赖加工电脑安装字体。与只在定位PDF展示、不可送入机器的板外形/孔轮廓、尺寸引线和图框区分。定位PDF提供实际板面总览、必要局部放大、基准与可找的边缘定位尺寸或坐标表、实际字形/线宽/点位尺寸和阅读方向。交付前同时查看裸板镭雕预览及叠加当前器件的预览，逐框核对中英文齐全、英文与对应转接件一致、文字完整位于框内，以及数量、方向、孔口避让和新版布局一致；预览与核验记录留在内部，师傅包仍只放规定文件。

## 镭雕图以信息完整、能定位为准

用户提供的 DWG/PDF 示范要实际读取，学习其为加工者提供的信息，不只模仿图框、配色或标题栏。示范中的其他零件、尺寸、数量和旧订单不是当前加工范围。按下表核对新图，缺少的内容补到对应零件图中；不得仅凭“样式相似”宣称可镭雕。

| 师傅必须能确定 | 图纸/文件必须提供 |
| --- | --- |
| 是哪件、做几件 | 可读名称、唯一零件编号/修订、与 STEP 和加工清单对应的件数 |
| 刻什么、刻多大 | 完整文字/图形，真实字形轮廓、实际字形外框宽高或已确认字高；字体名义字号不能代替实际字高 |
| 刻哪一面 | 从当前真实 CAD 提取的零件视图、清楚的打标面；用相邻面、孔位或不对称特征帮助辨认 |
| 刻在哪里 | 局部放大图与实际可找的边缘/孔/基准定位尺寸；平面编号优先标字框距该面外框的左、右、上、下距离，清楚说明尺寸量到字形外框而非文字中心/基线。异形面或功能刻线沿已确认功能基准标注，不硬套矩形边余 |
| 正反和阅读方向 | 外侧观察方向、字右/字顶、装夹方向；必要时标面原点及其 STEP 坐标。坐标、U/V 向量不能代替师傅可直接使用的定位尺寸 |
| 如何导入加工 | 每面 1:1 mm 字形/刻线 DXF，不缩放、不镜像；PDF 放大或缩小须标明其自身比例。参考轮廓、孔、图框、尺寸和引线不进入机器打标内容 |
| 表面如何处理 | 当前材质、表面处理、打标颜色及先后工序；激光打标，不铣刻。功率、速度、遍数由同材同处理试样确定，不从历史凹字深度推定 |

镭雕矢量与面坐标绑定、表面映射及网站元数据按 [激光打标交付](../../zzlab-optics-library/references/laser-marking-delivery.md) 核验。来源 SHA 和完整审计记录留在内部证据；师傅版以零件编号/修订关联图模，避免用技术追溯信息挤占定位图。

## 交付核对

- 清单、文件夹、图纸标题、STEP 和镭雕内容对应同一零件及修订，数量一致；重打包不擅自重建已验证主体。去掉图纸中指向已排除总册、JSON 或旧目录的失效说明，改指本文件夹内的实际文件。
- 核对镭雕面的真实几何、方向、字形尺寸和边余；从外侧正读，采用正交面坐标时检查 `U × V = N`。位置尺寸来自当前实体，不能按截图估计。
- 光路模块底板逐项核对器件定位框/编号、每框内部的器件中文名及与对应转接件一致的英文刻字、安装朝向/点位、名义光路与端口及适用的预留区；逐框核对两项文字均进入机器 DXF 且完整可读，缺项须补齐或记录用户明确豁免，不能以只有铭牌、编号或框外图例的底板判定镭雕完成。
- 逐块核对[黑白 HKSOP 标识](breadboard-logo.md)及两行字标实际进入 1:1 mm DXF，定位 PDF 与裸板/叠加预览一致；保留实心区、负空间和字母内孔，整体等比缩放，实际尺寸与孔口/器件避让通过。
- 读回 STEP 与 DXF，渲染所有新改 PDF 页，实际检查字体、尺寸引线、定位信息及无重叠/裁切。机器 DXF 仅实际闭合轮廓且无字体依赖；已有功能刻线保留真实尺寸、内孔和方向。
- 核对 ZIP 成员只含允许内容，检查 CRC 和成员完整性/哈希；将回执留在包外。已存在的孔配合、螺纹等级或薄壁工艺等关键未决项保留在对应图纸，不能把文件齐全称为实物加工或首件验收通过。
