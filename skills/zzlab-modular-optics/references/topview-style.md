# 元件俯视图外观协议 v1

样式标识：`zzlab-shaded-metal-v1`。2026-10-08 用户要求：新元件统一采用原库 PBS、波片、耦合头的金属明暗与细边缘质感。适用于元件库/画布里的器件外观；工程图继续采用工程制图规范。

## 显示要求

- 有真实完整 STEP 时，用真实装配从 +Z 向下做正交着色投影，+X 向右、+Y 向上，透明背景。保留装配遮挡、曲面高光、孔口阴影与细边缘；不要以每零件纯色投影、包围盒或 HLR 线框代替正式元件缩略图。
- 旧版已标定、带金属质感的图片继续沿用。新图先同旧 PBS/耦合头并排比对，再在正常缩放的混合画布里检查。几何/hash 校验不能替代外观验收。
- 可复用 [render_topview.py](../scripts/render_topview.py)。需要 OCP 8、VTK 9.6（本次实际验证环境），不需要 CadQuery、AI 绘图或在线渲染。Phong、受控双光源、SSAO 和特征边缘实现旧库观感；每张最长边不超过 900 px，SVG 只嵌入一张透明 PNG，不把网格/3D引擎带入浏览器。
- 原装配颜色可保留。源文件的工程识别色（如新零件青绿色）可改用旧库冷灰金属/深灰表观，但每个覆盖必须在 job 的 `colors` 按叶件名称显式登记；这只是显示配色，不改制造材料。原厂参考件未知材料不能从颜色反推。
- 不添加不存在的螺钉、镜片、刻字或外壳。允许来源已声明的名义光学片/五金包络，但必须保留其参考状态。非实物检查体（例如通光检查圆柱）按明确名单排除并记录。
- 仅有厂家尺寸图的激光器及资料卡继续用已标定尺寸示意，可用柔和明暗/边线协调外观；不得伪造详细 CAD 或消除“待实测/仅参考”说明。面包板孔网、选中框、碰撞轮廓及光线是交互覆盖层，不烘焙进器件图片。

## 定位与数据不变量

纯样式升级必须逐项保持 kit ID、所有坐标/单位、`widthMm/heightMm/anchorXMm/anchorYMm`、原 SVG `viewBox`、旋转规则、底座、真实安装孔、碰撞轮廓、光学面/端口、BOM 和用户参数不变。禁止因自动裁白边或视觉居中而移动光心。相机使用给定毫米范围，不用自动 fit/recenter；透明空白是定位的一部分。

有运动的模块：完整图、固定层、移动层使用同样材质和光照；按真实叶件分组保持原图框和各自原点，不能把总装图同时当两层。原来分层近似遮挡的限制仍保留。

## 输入、验收与交付

渲染 job JSON 是数组，每条包含：

- `id`, `stepPath`, `stepSha256`：本次对应的冻结总装，路径相对项目根。
- `originalSvg`, `originalSvgSha256`：既有 SVG 或新器件已标定的 SVG 图框；基线 SVG 要随证据冻结。可用 `--frames-root` 指向旧图副本。
- `boundsMm: [xMin,yMin,xMax,yMax]`：CAD 坐标范围，对应 `[-anchorX, anchorY-height, width-anchorX, anchorY]`。
- `excludeNames`/`includeNames`：可选，按实际 STEP 叶件精确名称选择；无对应叶件立即失败。
- `colors`：可选，叶件名称到 RGB 0..1 三数；列出配色依据，不代表材质核验。

```text
python -B scripts/render_topview.py --root 项目目录 --jobs jobs.json --frames-root 冻结旧图目录 --out 新图候选目录
```

输出 SVG、透明 PNG 和报告：源 STEP SHA、叶件数量、排除名单、配色、像素尺寸、三角面数、毫米图框和新 SVG SHA。OCP/VTK 或 GPU 不同可造成像素 hash 不同，应重新验收并记录，不以 hash 相同代替视觉核对。

验收须涵盖：透明背景、无遮挡层穿透/遗漏、无裁切或镜像、孔与原点叠对、整体/运动分层显示、正常缩放的旧新混合画布，及纯显示变化的不变量比较。图纸/STEP 不因换质感而重新设计。

先在独立候选目录验证，正式库仍经 `stage/adopt/build`。对同路径图片使用 `replace` 并绑定旧 SHA，同步所有运行引用的图片 SHA 及派生索引；证据中的历史 SHA 留在冻结旧图副本和历史审核中。不得改用户数据库、购物车和工程状态来替换图片。按已有授权发布后，把标准包、更新 skill、前后对比、实际验收/上线回执及 SHA 清单交付 NAS，并追加项目日志。
