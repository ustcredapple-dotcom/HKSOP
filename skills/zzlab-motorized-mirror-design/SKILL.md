# ZZLab 电动镜架设计

把原厂手动微调镜架变成有可复建源、分件图纸、明确光学基准和真实验收证据的电动模块。用户指定型号、口径、镜厚与连接方式优先；已有模块先核对后复用。修改既有架构保留稳定 ID 并更新修订身份，新模块才采用新 ID。

## 输入与路由

先定位当前项目源记录及最后交付清单，核对其哈希；不要以文件名或旧 `passed` 判断最终版本。取得镜架型号/原厂 STEP、镜厚、电机本体及输出接口、目标光高、柱与转接件、调节方向和需要保护的通光区域。缺少关键接口时先推进可独立部分，将缺值记为待核实，不借另一个型号补齐。

- 原厂接口、长杆/浮动机构与通光约束：读 [references/mechanical-workflow.md](references/mechanical-workflow.md)。
- 继承项目 V2 时：读 [references/v2-baseline.md](references/v2-baseline.md)，其中是版本实例，不能变成其他型号的默认尺寸。
- 加工图：孔径、螺纹、深度、沉孔和入口须用孔旁紧凑短引线标注（保留原定位尺寸，不逐孔堆审核说明或另加整页）；孔位和基准沿用原定位方法（包括原坐标表）；孔规格表仅补充。同规格组孔可合并数量规格；歧义用剖视/详图消除，未知不猜。具体交接要求见 [references/library-handoff.md](references/library-handoff.md)。
- 元件化与交接：读 [references/library-handoff.md](references/library-handoff.md)。项目提供 `zzlab-modular-optics` 或 `zzlab-optics-library` 时按当前源中的协议核验，不假定其他电脑已安装这些 skill。
- 给师傅的加工包：读 [加工包默认规范](../zzlab-modular-optics/references/machinist-package.md)。按独立加工件分类，根目录只放简明加工清单；仅含必需三视图、单件 STEP、镭雕定位 PDF 和 1:1 DXF，定位尺寸须能直接用于打标。与完整设计/元件库交接包分开。

## 设计与验收循环

1. 从原厂来源和真实 BRep 建立接口表，分别列来源、单位、计算/测量方法及未知项。保留原厂精密调节螺钉；H2 是插入 2 mm 内六角口的驱动接口，不等于 M2 螺纹。不要缩放商业件来换公制光高。
2. 用真实后座加镜厚求光面，求柱/转接高度链，再选电机安装面与杆长。区别镜片直径、前座净孔和后框完整通孔。保护后孔时，从真实后外表面沿光轴延伸到最远部件之外，检查电机、板、导向、杆、套、盖、紧固件、柱和转接件。
3. 先对照用户原有模型的总高、加工件数和驱动链，优先只改必要尺寸。ZZLab V2 竖直镜架优先保留高位原 11 mm M3→H2 一体杆，只加长低位 H2 段，并以原高位电机安装面做共面；不为未要求的全行程默认加独立套筒、套盖、导向或抬高支架。只有真实接口/指定行程检查证明原方案不够，才给有依据的最小改动。延续项目原生 CAD 或生成参数化 CadQuery/OpenCascade 源。分件优先加工与装配可达，需要连续支撑和实际紧固连接，不能靠删除连接件得到空孔。长杆检查旋转包络、偏心余量、原螺钉轴向进退及有效啮合；固定电机不得刚性顶住随螺纹进退的调节器。
4. 检查逐件有效实体/连通性、STEP 往返体积、接合孔、螺纹啮合/孔底余量、装配顺序和工具通道。执行静态几何、浮动端点与实际实现的运动包络检查。材质、公差未确认时继续给可审核图模，将制造放行列为待定。
5. 修正实际失败，重跑受影响检查；图模一致后保存完整设计资料：BOM、分件/总装 STEP、三视/剖视/孔坐标图、布局 SVG 与审计 JSON。给师傅的加工包按上面的独立规范精简导出。截图不是加工工程图；镜片是否含于 STEP 要按叶件核对。
6. 按正式 stage/adopt/build/derived-index/strict 流程元件化。交接绑定源、生成器、参数、证据和逐文件 SHA；接收端版本不同就制作精确兼容链，不能直接覆盖。

## 可执行几何检查

`scripts/verify_nominal.py` 独立检查命名 STEP 的输入 SHA、完整叶件集合、有效实体、指定加工件单一连通实体、共面电机及圆柱保护区域。配置中列齐 `singleSolidLeafNames`。仅明确标注的非物理审查体可排除，排除名单写入回执。它不替代驱动运动、紧固件/孔及工具检查。

按 [references/checker-input.md](references/checker-input.md) 编写检查 JSON，然后运行：

```text
python -B scripts/verify_nominal.py --config 当前设计检查.json --output 新几何回执.json --cad-deps 本机CadQuery依赖目录
```

已安装 CadQuery 时省略 `--cad-deps`。缺少环境就报告未执行，不生成虚构 `passed`。

## 报告与边界

中文正式报告每个问题依次使用 **现在存在哪些问题：**、**模拟做了什么操作：**、**模拟结果是什么：**、**可能在实验中出现的问题：**。来源尺寸、名义计算、实测和条件性预测分别标明。只记录实际执行的计算；零布尔交体不证明公差、摩擦、扭矩、振动、实物光学校准或完整带电行程合格。

当前任务决定同步范围；调用 skill 不自动授权上传云端、网站上线、给其他人发消息或驱动实机。按用户已授权目的地交付，并分别陈述本地建模、NAS 复制、云导入与实物测试状态。


## 元件库俯视图质感

向标准光学元件库交付时，遵守 [俯视图外观协议](references/topview-style.md)：用真实完整 CAD 正交着色，统一原库的金属明暗、孔口阴影和细边缘；不要交付纯色块/包围盒作为有 CAD 元件的最终图。保持原图框、安装孔和光学基准，附渲染报告及混合画布视觉验收。本站接收 skill 为 `zzlab-optics-library`，本条随跨机设计 skill 同步交付。
