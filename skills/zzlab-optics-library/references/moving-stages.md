# 手动位移小面包板运行协议

能力标识 `zzlab-stage-motion-v2`。这是元件库可信定义与现有工程 v1 的增量扩展。导入工程必须声明 `requires: ["zzlab-stage-motion-v2"]`；不识别该能力的工具不能将它降为静态小板。

## 定义和实例

- `catalog.stageModules` 保存来源冻结的模块、版本、固定安装孔、实际顶板可用孔、运动轴、限位、叠层、保守碰撞体和 BOM。当前仅支持单轴、单层子板，模型内部机构不作为可执行代码载入。
- 元件库卡片对应 `kit.stageModuleId`。它的普通 `layout.placementAllowed` 为 false，须经 `addStageModule` 建立子板；不能建立普通光学实例。
- 顶板是 `registeredBoard.stageOnly: true`，以真实板厚和孔表登记，不能脱离位移模块作为普通板导入。预留区域不生成虚构螺纹孔。
- 工程的 `subBoard.stageMotion` 只包含 `moduleId`、`revision`、`qMm`。目录控制几何和文件路径，工程不能覆盖。

`subBoard.xMm/yMm` 是**当前移动顶板左下角**。固定基准位置为 `topOrigin − R(centerTopOrigin + q × axis)`。改变 q 只平移顶板及其局部子器件，固定底座、安装孔和原厂参考层不动。旋转整个模块则同时旋转两层。q=0 是机械行程中位；未完成标定时测微头中位读数为 null，不能视为读数零。

## 安装、运动和高度

固定底面以 `runtime.baseBoundsMm` 检查承载区域；上板可悬出。固定孔必须与承载板真实螺纹孔重合，桌子模式除外。调整 q 后不将顶板重新吸回母板孔网格。上板子器件安装只用其实际可用螺孔，仍核对整组安装孔。

位移台专用顶板（可信目录 `registeredBoard.stageOnly: true`）连接台身的原固定孔允许被本板上的器件覆盖：装配时先固定顶板，再装上方器件。适用于已登记的 LS30 左右型（含 R3）、MT1/M、PT1/M、LS35x.Lab.E。前后端布局校验一致采用此规则；不修改孔身份、孔径、制造资料或已有工程。固定基座与母板的对孔检查、子器件真实螺孔匹配、普通面包板遮挡及跨模块碰撞保持不变。工程实例不能自行声明这项豁免；位移台不通过自动/手动选孔新增安装孔。

子器件相对母板顶面的高度 = 模块实际总高 + 模块额外垫高 + 器件光高及器件额外垫高。真实顶板厚度不被总高替换，`stageHeightOffsetMm` 只补厂家位移台与下转接板，避免重复计高。光路跟随移动后的真实 XY 与 Z。

碰撞检查使用厂家机构的全行程保守包络，加上**当前 q** 的上板包络。`fullTravelSweep` 是极限扫掠报告，不代表已验证所有中间位置的实体干涉。自己的子器件与自身承载结构不当作外部碰撞；与其他组仍做保守检查。旋钮及厂家内部机构的 CAD 图保持原来源姿态，不能据画面宣称实物机构中位已校准。

## 保存、出单和资料

保存、复制、撤销和共享保留模块版本、q 以及子器件局部坐标。单模块共享仍使用一个桌面载体加一个位移子板的工程结构，不能展平丢失运动状态。

每个位移模块按可信 BOM 展开一次；顶板已含于模块 BOM，不再重复生成参数面包板。子器件照常计入采购与制造。原厂位移台为采购件，自制上下板为制造件；标准螺钉未知材料、表面处理不补猜。原输入包采用 316L。用户在本次载入时将自制上下板统一改为 7075 铝合金、黑色阳极氧化；R1-A7075 版生产清单和图纸以此为准，原厂位移台不随自制件材料变更。

R1 中 LS30 左右型、MT1/M 顶面高为 37.5 mm；PT1/M 为 50 mm，均以冻结 CAD 实测名义尺寸构成。型号选定、资料核验通过与实物验收是不同状态；当前制造审核、实物中位与装配验收仍分别保留来源状态。

## 必须验证

四种旋转和工作限位；非整网格 q；固定基准不变；子器件 XY/Z；孔相位；固定底座越界而非上板越界；工程能力及版本拒绝；复制与共享不展平；BOM 不重复；导出层图、STEP/PDF 的源 SHA；旧工程与权限回归。修改运行程序需重新生成交互索引及其程序指纹。
